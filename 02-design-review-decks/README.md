# 02 — Design Review Decks

The design exploration journey, in order. Each file is an HTML "deck" you open in a browser.

## Files (in iteration order)

### `01 - The Signal - First Pass.html`
The initial exploration. Rough shape of the brand, early type experiments, first look at guest-pack concepts. **Archive — don't use as reference for current work.**

### `02 - The Signal - Review.html`
Second pass after first round of feedback. Direction started to settle here.

### `03 - The Signal - Review v2.html` ← **current**
The latest agreed direction. This is what everything downstream (guest packs, social cards, etc.) is built against. **Start here for anything new.**

### `03 - The Signal - Review v2 (standalone).html`
Same as above but with all fonts/images/CSS inlined. Use this to send to someone outside the team — works offline, no folder structure required.

### `03 - The Signal - Review v2 (download).html`
Alternative standalone export. Functionally identical to the one above.

## How to open

Double-click any file — it'll open in your default browser. The non-standalone files need the sibling folder `../01-brand-system/` to be in place for fonts/logos to load correctly.

## If you're reviewing

Open the standalone version (`... (standalone).html`) — it's self-contained and always renders correctly.

## If you're editing

See `../05-source-code/` — the decks are assembled from React components in there.
