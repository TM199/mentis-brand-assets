# 04 — Source Assets

Raw photo assets. Drop-in ready for decks, social cards, guest packs, anything.

```
04-source-assets/
├── guest-photos/
│   ├── kamaal-watkins.jpeg
│   └── kevin-oti.jpeg
└── team-photos/
    ├── trisden.jpg
    └── trisden-alt.jpeg
```

## Usage notes

- **Guest photos** are already embedded (base64) in the guest-pack HTMLs — these originals are here for re-use in social cards, promo graphics, thumbnails, and episode artwork.
- **Team photos** — two variants of Trisden. Use whichever suits the layout.

## Missing something?

If you need a photo that's not here (new guest, alternate crop, etc.), add it in the relevant subfolder following the same naming convention: `firstname-lastname.ext`, lowercase, hyphenated.
